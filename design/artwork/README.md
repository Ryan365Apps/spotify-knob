# the 60 — artwork pipeline (design/artwork)

Line-art / blueprint promotional artwork for the 60, produced from the CAD exports
in Blender 5.2 and driven by script. Everything in this folder was built and
verified live on Blender 5.2.1 LTS on 2026-09-02.

## Folder

| path | what |
|---|---|
| `blender/the60_lineart.blend` | the working scene: v7.1 parts, three line weights + glow, explode rig, three styles, backdrop, ENCODE scene. Images are packed, so the file is self-contained. |
| `scripts/the60_lineart_pipeline.py` | the whole pipeline as functions (build scene, line art, explode rig, backdrops, styles, frame render, MP4 encode). Edit `PARTS_DIR` / `OUT_DIR`, run in the Scripting tab, then call `build_all()`. |
| `examples/` | renders: paper-grey exploded still, blueprint still, neon still, and two blueprint reels (`_reel` = 12 deg drift, `_loop` = one full turn, seamless loop). |
| `examples/backgrounds/` | generated backdrops (blueprint grid, neon hex). Regenerated by the script; kept as samples. |
| `the60-artwork-pipeline.html` | the long reference sheet (rev C), not yet copied here - live copy: https://claude.ai/code/artifact/4aaf6445-12e8-41af-836a-3d093180b476 . Written before live verification; where it disagrees with this README or the script, the README/script are right. |

## The look (decided 2026-09-02)

* **Blueprint** is the chosen style: Prussian-blue ground `#1B4FA3` (vignette to `#0E3272`, paper grain), 5 mm minor / 25 mm major grid in true millimetres at the render's scale, off-white lines `#EEF3FF`, dashed hidden lines at 40 %.
* Three line weights, as Grease Pencil stroke **radius in mm** (the camera is orthographic so the weight is constant across the frame and scales with resolution automatically): heavy silhouette 0.70, light interior edges 0.25, hidden 0.18 @ 40 % (occlusion levels 1-4).
* Camera: true isometric (rotation X 54.7 deg, Z 45 deg), orthographic, parented to the `CTR` empty at the device's centre. Reel = 1080x1920, ortho scale 330 (applies to the long side).
* Rule from the product vision: colour only ever comes from light. The blueprint is monochrome; the halo is the only thing allowed to be coloured when it is added.

## The rig

* `CTR["explode"]` (0-1) drives every large part's Z through a driver expression
  `REST + max(0, min(1, (var - delay) / (1 - delay))) * distance`, so the parts leave in sequence. Base shell is the anchor. Plan in `EXPLODE_PLAN` in the script.
* Keyframes on `explode`: 1 -> 0, 75 -> 1, 150 -> 1, 195 -> 0. Hidden-line layer opacity fades in 55-95 and out 160-200. `CTR` rotation Z 0 -> 360 deg **linear**, last key at frame 211 so frames 1-210 loop seamlessly.
* Small parts (rocker, drive plate, tyre hub, collars, bushes) are hidden for artwork. The knurled knob is replaced by `knob_body_smooth` because the knurl turns line art into noise.

## Blender 5.2 facts learned the hard way

* STL comes in unwelded; run Merge by Distance (`remove_doubles`) before anything else or every triangle draws.
* After importing geometry, Line Art does not redraw until its modifiers are toggled off/on (`refresh_lineart()` in the script).
* Grease Pencil layers: turn **Use Lights off** on every layer or scene lights darken the strokes.
* Line Art modifier fields: `radius` (scene units), `opacity`, `use_multiple_levels` + `level_start/end` for hidden lines, `use_edge_overlap` for CAD meshes, `use_cache` on the 2nd+ modifier.
* Dot Dash modifier filters layers via `tree_node_filter = "hidden"`.
* Video output moved: Output > **Media Type = Video**, then FFmpeg / MPEG-4 / H.264. `image_settings.file_format='FFMPEG'` only works after `media_type='VIDEO'`.
* Actions no longer expose `.fcurves`; delete/insert keyframes via `keyframe_delete` / `keyframe_insert`, and set interpolation through Preferences > Edit > new-keyframe interpolation before inserting.
* Creating and deleting a temporary compositor node group crashed Blender once. The neon glow is therefore a 4th Line Art layer (radius 2.2, opacity 0.18) rather than a compositor bloom.
* **When driven from the Claude connector**: a single blocking call over ~60 s drops the link. Render animations one frame per `bpy.app.timers` tick (`render_frames()`), then encode from the PNGs (`encode_mp4()`). ~1.5 s/frame at 1080x1920 for this scene.

## Re-render checklist

1. Open `blender/the60_lineart.blend`, start the MCP add-on server if working with Claude.
2. New CAD: delete the contents of `PARTS`, run `build_scene(r"...parts")`, then `build_explode()` (drivers keep working if part names are unchanged).
3. `set_style("blueprint")` (or `"paper"` / `"neon"`), `reel_format()` for portrait.
4. `render_frames(r"D:\...\frames_blueprint")`, wait for `bpy.app.driver_namespace["the60_render_state"]["done"]`.
5. `encode_mp4(frames_folder, r"D:\...\the60_explode_blueprint_loop.mp4")`.
6. Check the MP4 on a phone before posting; if thin lines shimmer, raise `LA_light.radius` to ~0.35 and re-render.
